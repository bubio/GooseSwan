# Session 2026-11-07 — M0 scaffolding

## Built
- `src/sst.goose`: SingleStepTests harness (streaming JSON reader; load initial
  regs/RAM, execute one instruction, compare listed final regs/RAM) plus a
  minimal 8086 core slice.
- Implemented: segment-override prefixes (26/2E/36/3E), ModRM + 16-bit
  effective addresses, MOV (88/89/8A/8B, C6/C7, B0-BF), ADD (00-05) with full
  flags (CF/PF/AF/ZF/SF/OF).

## Results
14 opcode files × 2,000 cases = **28,000 cases, all passing, 0 failures**
(88, 89, 8A, 8B, C6, C7, B0, B8, 00, 01, 02, 03, 04, 05; total run ~0.2 s).

## Lessons from the corpus
- Each opcode file also contains the same instruction preceded by segment
  override prefixes (~half the cases). Prefix handling is not optional.
- On the 8086, C6/C7 execute as MOV for every value of the ModRM reg field
  (the /0-only rule is a documentation fiction). Whether the V30MZ matches
  is an M1 question for WSCpuTest.
