# 2026-11-08 — M5: the frontend (window, input, audio out, saves)

## Machine/frontend split

run_ws was refactored into `ws_boot()` + `ws_frame()` in bus.goose
— boot the machine from the global `rom`, then run one
40,704-cycle frame with the current keys_state (interrupt
delivery, TF trap, halt burn and the KEY_PRESS edge live inside
ws_frame). The headless runner keeps its scripting and stop
conditions on top; behaviour is unchanged (full battery below).
An unsupported opcode now sets `ws_unsupported` instead of exiting
inside the loop; the runner reproduces its old message and exit.

Two harness globals the core secretly used (`recording`,
`touched`, written by wb8) moved from sst.goose into cpu.goose —
the frontend program exposed the dependency.

## The frontend (src/gooswan.goose + src/front.goose)

- gfx::open at 672x432 (224x144 x3, NO_VSYNC — pacing is ours),
  the framebuffer uploaded per frame into an RGBA8 texture and
  drawn as one fullscreen triangle sampling it (two tiny
  embed_shader GLSL programs, NEAREST/CLAMP).
- Input: Y pad = WASD, X pad = arrow keys, A = X, B = Z,
  Start = Return, Escape closes.
- Audio: the audio package is an SFX mixer, not a stream, so each
  frame's 24 kHz samples (318 stereo frames) become one short
  sound, played immediately; finished voices are retired and
  their sounds released every frame, so the fixed tables never
  fill. The mixer resamples 24k -> the 48k device rate.
- Pacing: 40,704 / 3,072,000 s per frame against gfx::time(),
  resyncing after hitches over 250 ms.
- Saves: ws_load_saves/ws_save_saves in bus.goose — <rom>.sav
  (SRAM), <rom>.eep (cartridge EEPROM, only when fitted),
  <rom>.iep (internal EEPROM); loaded at boot, written on exit
  and every 600 frames.

## Verification on a GPU-less VM

This VM has no GPU, but Mesa lavapipe (mesa-vulkan-drivers
25.2.8 noble build, extracted under ~/workspace/tools/mesa-vk)
gives SDL_GPU a Vulkan device, so the whole path really ran:
GOOSE_GFX_HEADLESS=1 + the lvp ICD + SDL_AUDIODRIVER=dummy,
`gooswan WSHWTest.wsc 300 check` reads the presented screen
back and compares every pixel with the framebuffer:
mismatches=0 of 32256 (orientation and NEAREST sampling exact),
pacing lands at ~13.3 ms/frame, .sav/.iep files written, and a
second run loads them back cleanly. The audio pump runs against
SDL's dummy device without errors; audible quality on real
hardware is still the user's check to make.

Full regression unchanged: corpora at baseline (8086
634406/646000, V20 2980747/3125000), apu_test 83/83, ppu_test
39/39, eeprom_test 25/25, WSTimingTest 400/407 full harvest,
WSHWTest Test All 0 failures, fb_check 3/3.
