# 2026-11-07 — APU wave channels + sweep + GDMA (M4 slice)

## Result

- **Wave channels**: all four oscillators modelled after Swanium
  (period counter, 32-step wave index, current 4-bit sample, bulk
  advance over the cycle delta; wave data read from WRAM at
  `(port 0x8F << 6) + ch*16`). CPU-visible surface: the SND_CH_OUT
  readback ports **0x96–0x9B** now return the live mixer sums
  (sample × volume nibbles per side, channel 4 replaced by the
  noise DAC level in noise mode, voice mode adding the raw 0x89
  byte to both sides). The audible sample stream itself is still
  not generated — that arrives with the M5 frontend.
- **Sweep** (channel 3): an 8193-cycle sweep tick; on each tick the
  step counter either decrements or reloads from SWEEP_TIME and
  applies the signed delta to the pitch ports, wrapping
  (>2047 → 0, <0 → 2047). Writing SWEEP_VALUE/SWEEP_TIME resets
  the timer (WSHWTest's "Write resets timer" case). The fast-sweep
  test bit (SND_TEST bit 1) steps once per cycle after a one-cycle
  prime.
- **Port-access timing**: IN/OUT accesses land partway through the
  instruction, which the fast-sweep CPU-cycle case measures
  exactly. The sweep is pre-charged once per IN/OUT instruction
  (5 of 7 cycles before an OUT imm8 write lands; 4 cycles into an
  IN imm8 sample point; DX forms 3/2), and `apu_tick` skips the
  prepaid part of the next delta, so per-instruction totals — and
  therefore the WSTimingTest fit — are unchanged. A simpler
  "+1 cycle on pitch reads" model was tried first: it passed the
  fast case but inflated sweepMeasure's dense pitch polls by ~1
  cycle each and failed the timing cases; the pre-charge model
  passes both.
- **GDMA**: synchronous burst on the port 0x48 enable write —
  byte copy from any physical source to WRAM, increment or
  decrement, aborting if the source enters SRAM (0x10000–0x1FFFF)
  or the ROM-wait window (0x80000–0x8FFFF while SYSTEM_CTRL1 bit 3
  set); pointers/length written back, enable self-clears, the
  GDMA-complete cause (bit 3) latches masked by INT_ENABLE, and
  the runner is charged 5 + bytes cycles.
- **Scanline-match cause**: reaching the LCD compare line
  (port 0x03) now latches cause bit 0x10 masked by INT_ENABLE.
- Sound DMA / HyperVoice are not modelled (Colour-only PCM path;
  no test asset exercises them; noted as an M4 leftover).
